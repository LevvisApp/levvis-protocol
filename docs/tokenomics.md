# Tokenomics: draft framework

> **Status: framework only.** No supply, allocation, vesting schedule or contract address has been announced. Every figure that would appear here is intentionally left blank rather than guessed. When a fact is stated, it is recorded in `src/register.js` first and mirrored here.

## Open fields

| Field | State |
| --- | --- |
| Contract address | absent |
| Total supply | absent |
| Allocation split | absent |
| Vesting / lock terms | absent |
| Fees | absent |

## Design intent (non-binding)

1. **Utility before speculation.** Any token role should connect to running analyses: access, priority or settlement of runs.
2. **Legible rules.** Allocation and schedules should be short enough to read in one sitting and verifiable on chain.
3. **No surprise levers.** Anything that can change supply or fees must be disclosed with the contract address.
4. **Honest labelling.** Marketing surfaces must never present an unconfirmed figure as settled.

## Verification checklist for the day numbers land

- [ ] Address recorded in the register with state `stated`
- [ ] Address checked on the Robinhood Chain explorer
- [ ] Supply and allocation published together
- [ ] Lock and vesting contracts linked
- [ ] Site CA slot switches from inert to copyable

This is a description of an unfinished plan, not financial advice or an offer of any kind.
